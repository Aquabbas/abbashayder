A NeoVim configuration built on <a href="https://www.lazyvim.org/" target="_blank" rel="noopener noreferrer">LazyVim</a> for developers who want a functional IDE-like setup without configuring LSPs, linters, and formatters from scratch.

## Why?

Setting up NeoVim from scratch can be fun, but sometimes you just want something that works. This is the configuration I wished I had when I started using NeoVim in 2023.

## Features

- Pre-configured LSP, Linter and Formatter support for PHP, TypeScript, Rust, Gleam, and more
- Buffer-style file explorer with <a href="https://github.com/stevearc/oil.nvim" target="_blank" rel="noopener noreferrer">oil.nvim</a>
- Seamless [tmux](https://github.com/tmux/tmux/wiki) pane navigation
- [Obsidian](https://obsidian.md) vault integration for notes
